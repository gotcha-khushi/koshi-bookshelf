
# Koshi's Bookshelf

**Koshi's Bookshelf** is a personal digital bookshelf. I made it to keep track of my reading, rate books, and write reviews and thoughts about the book.

I like reading books that make me think, and I wanted somewhere to keep my reviews instead of forgetting everything after finishing a book. I also wanted to make a website with a design I actually liked, so I went with a vintage bookshelf look with book spines and a paper-like background I wanted the spines to look like they're part of book itself so I manually added color to them.

## What it does

- Shows my books as spines on a bookshelf.
- Lets me keep my own reviews, ratings, authors, and reading dates together.
- Has a light and dark theme.
- Clicking on a book shows its details and review.
- Includes an About Me page where there's a small introduction to myself.
- it also has an Admin section which I'm planning to use to add more books and reviews and edit reviews I'm still working on it

## Built with

- HTML
- CSS
- JavaScript
- JSON
