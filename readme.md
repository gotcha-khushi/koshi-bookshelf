
# 📚 Koshi's Bookshelf

*A little corner of the internet for the books I've read, the thoughts they've left me with, and the stories I want to remember.* ☀️

**Koshi's Bookshelf** is a personal digital bookshelf built with HTML, CSS, and JavaScript. It lets me keep track of my reading, rate books, and write reviews based on my own interpretations and experiences. 📝

## 🍂 About the Project

I wanted to make something more personal than a reading list. A place where I could collect books and write down what I actually thought about them, whether I loved them, found them strange, or kept thinking about them long after finishing them.

The website has a warm, vintage-inspired design, with book spines arranged on a shelf and a paper-like background. It's designed to feel like a little digital reading space rather than just another book-tracking app. 📖

## ✨ Features

- 📚 **Interactive bookshelf** — Browse books displayed as colourful spines on a shelf.
- ✍️ **Book reviews** — Read my personal thoughts and interpretations of each book.
- ⭐ **Reading details** — View book titles, authors, reading dates, and ratings.
- 🌷 **About Me** — A little introduction to the person behind the bookshelf.
- 🌙 **Light and dark themes** — Switch between themes to suit your reading mood.
- 💻 **Responsive layout** — Designed to be usable across different screen sizes.

## 🛠️ Built With

- 🌐 HTML
- 🎨 CSS
- ⚡ JavaScript
- 🗂️ JSON for storing book and about-page content

## 🚀 Running Locally

1. 📥 Clone this repository:

   ```bash
   git clone https://github.com/gotcha-khushi/koshi-bookshelf.git
   ```

2. 📂 Open the project folder.

3. 🖥️ Run the website using a local development server, such as the **Live Server** extension in VS Code.

   A local server is recommended because the website loads its book data from JSON files.

## 💭 Why I Made It

I like reading books that make me think, question things, and look at the world a little differently. I wanted a place to keep those thoughts instead of letting them disappear after I finished a book.
